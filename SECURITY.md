# Security Policy

## Reporting a Vulnerability

This project has a very limited attack surface and is not expected to expose significant security sensitive functionality.

That said, security issues can still happen. If you find a vulnerability or something that looks security relevant, please report it privately rather than opening a public issue.

You can report security issues through:

* **GitHub Private Vulnerability Reporting**, available through the repository's **Security** tab.
* **Email:** `info@legasanpetrux.org`

Please include a short description of the issue and steps to reproduce it.

Thanks!
